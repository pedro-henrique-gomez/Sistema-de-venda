📋 VARIÁVEIS DE AMBIENTE (NECESSÁRIAS)

DATABASE_URL
├─ O quê: String de conexão do banco de dados
├─ Onde: Supabase, Heroku, ou seu provedor
└─ Exemplo: postgresql://user:pass@host:5432/db

JWT_SECRET
├─ O quê: Chave para tokens JWT
├─ Onde: Qualquer string aleatória e segura
└─ Exemplo: your-super-secret-key-12345

⚠️ POSSÍVEIS ERROS E SOLUÇÕES
═════════════════════════════════════════════════════════════════════════════

"Git não encontrado"
→ Instale: https://git-scm.com/download/win

"Vercel CLI não encontrado"
→ Execute: npm install -g vercel

"Não consigo fazer push"
→ Verifique: git config user.email e user.name

"Build falhou no Vercel"
→ Verifique os logs no Vercel Dashboard

"API retorna 500 em produção"
→ Configurou DATABASE_URL e JWT_SECRET?
