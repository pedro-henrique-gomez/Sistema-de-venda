# 🚀 Como Iniciar o Sistema Banca no Ponto

## 📋 Modo Fácil (Recomendado)

### 1. Iniciar o Sistema
- Dê **duplo clique** no arquivo `INICIAR_SISTEMA.bat`
- Aguarde o sistema carregar (aproximadamente 30 segundos)
- O navegador abrirá automaticamente em: http://localhost:3000

### 2. Parar o Sistema
- Dê **duplo clique** no arquivo `PARAR_SISTEMA.bat`
- Todos os servidores serão fechados

---

## 📁 Arquivos Importantes

| Arquivo | Função |
|---------|--------|
| `INICIAR_SISTEMA.bat` | Inicia backend e frontend automaticamente |
| `PARAR_SISTEMA.bat` | Para todos os servidores |
| `README_INICIO.md` | Este arquivo de instruções |

---

## ⚠️ Requisitos

- **Node.js** instalado no computador
  - Se não tiver, baixe em: https://nodejs.org/
- **Conexão com internet** (para primeira instalação)

---

## 🔧 O que os arquivos .bat fazem?

### INICIAR_SISTEMA.bat
1. ✅ Verifica se o Node.js está instalado
2. ✅ Instala dependências automáticas (só na primeira vez)
3. ✅ Inicia o servidor backend (porta 3001)
4. ✅ Inicia o frontend (porta 3000)
5. ✅ Abre o navegador automaticamente

### PARAR_SISTEMA.bat
1. ✅ Para o servidor backend
2. ✅ Para o frontend
3. ✅ Fecha todas as janelas do terminal

---

## 📞 Suporte

Se tiver algum problema:
1. Verifique se o Node.js está instalado
2. Feche todos os programas e tente novamente
3. Execute o `PARAR_SISTEMA.bat` antes de tentar iniciar novamente

---

## 💡 Dicas

- **Primeira vez**: Pode demorar um pouco mais (instalando dependências)
- **Uso normal**: Demora cerca de 15-20 segundos para iniciar
- **Para fechar**: Use sempre o `PARAR_SISTEMA.bat` para evitar problemas
