🚀 PASSO 2: FAZER DEPLOY (5-10 minutos)
═════════════════════════════════════════════════════════════════════════════

Opção A: AUTOMÁTICO (RECOMENDADO)
  1. Volte para a raiz do projeto
  2. Clique 2x em: deploy-vercel-completo.bat
  3. Aguarde até terminar

Opção B: MANUAL
  1. No Vercel Dashboard
  2. Vá para: Deployments
  3. Clique no deployment mais recente
  4. Clique: "Redeploy"
  5. Aguarde terminar

🆘 SE ALGO DER ERRADO
═════════════════════════════════════════════════════════════════════════════

"Build falhou"
  → Verifique os logs no Vercel Dashboard

"API retorna 500"

  → Certifique-se que DATABASE_URL está correta
  → Tente redeploy

"Conecta mas não acessa dados"
  → Verifique se DATABASE_URL está correta

  → Tente rodar migrations manualmente
