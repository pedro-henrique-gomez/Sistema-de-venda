✅ CORRIGIDO - BACKEND
======================

1. File: backend/src/routes/vendas.js
   Lines: 384-394
   
   Issue: "TypeError: o.filter is not a function" no endpoint GET /vendas/resumo/hoje
   
   Root Cause: 
   - Código usado `venda.taxas?.filter()` com optional chaining
   - Quando venda.taxas é null/undefined, retorna undefined
   - Ao tentar chamar .filter() em undefined causa erro
   
   Fix Aplicado:
   ```javascript
   // ANTES (buggy):
   const taxaPagamentoValor = venda.taxas?.filter(t => ...) || 0;
   
   // DEPOIS (corrigido):
   const taxaPagamentoValor = (venda.taxas && Array.isArray(venda.taxas))
     ? venda.taxas.filter(t => ...) 
     : 0;
   ```
